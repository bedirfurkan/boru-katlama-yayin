# Boru Katlama Stüdyosu — sürümler

Bu depo yalnızca **Boru Katlama Stüdyosu**'nun program dosyalarını ve imzalı güncelleme bildirimlerini barındırır: Windows için `BoruKatlama.exe` + `surum.json`, macOS için `BoruKatlama-X.Y.Z-macos.zip` + `surum-macos.json`.
Program kendini buradan günceller; kaynak kod başka bir (özel) depodadır.

- Program **lisans gerektirir**: lisanssız açılmaz. Lisans için lisans sağlayıcınıza başvurun.
- Güncelleme bildirimi ve iptal listesi (`iptal.json`) dijital olarak imzalıdır; program imzası geçersiz hiçbir şeyi kabul etmez.
- **Sürümler** sayfasından indirilebilir (Releases). macOS: zip'i açıp `BoruKatlama` uygulamasını Uygulamalar klasörüne sürükleyin. Uygulama (2.4.1 ve sonrası) Apple Developer ID ile imzalıdır ve Apple tarafından notarize edilmiştir; ilk açılışta macOS yalnızca standart “internetten indirildi, açılsın mı?” sorusunu sorar. Güncellemeler ayrıca uygulamanın kendi imzalı bildirimiyle doğrulanır. (Daha eski sürümlerde ilk açılışta Sistem Ayarları > Gizlilik ve Güvenlik bölümünde “Yine de Aç” gerekebilir.)
